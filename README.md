# EXAMEN CONOCIMIENTO - QUALITY ENGINEER (QE)

## Descripción

Proyecto de automatización de pruebas para validar el proceso de inicio de sesión de una aplicación web.

La automatización fue desarrollada utilizando Java, Selenium WebDriver, JUnit y Maven.

## Tecnologías utilizadas

- Java
- Selenium WebDriver
- JUnit
- Maven
- Google Chrome
- Eclipse IDE

## Prerrequisitos

Para ejecutar el proyecto se requiere:

- Java JDK 8 o superior
- Maven
- Google Chrome
- Eclipse IDE u otro IDE compatible con Maven
